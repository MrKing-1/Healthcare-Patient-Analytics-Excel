# 🏥 Healthcare Patient Analytics Dashboard

## 📌 Project Overview

This project is an Excel-based Healthcare Patient Analytics Dashboard developed to analyze patient demographics, treatment patterns, department performance, emergency visit trends, and recovery indicators.

The dashboard transforms healthcare data into meaningful insights using Microsoft Excel, Pivot Tables, Pivot Charts, KPI cards, and interactive filters to support healthcare resource planning and decision-making.


# 🎯 Objectives

- Analyze patient distribution across healthcare departments.
- Identify treatment types with the highest patient volume.
- Compare routine and emergency visit patterns.
- Evaluate department workload and service demand.
- Monitor patient recovery performance.
- Generate actionable healthcare recommendations.

# 🔎 Key Insights

1. Orthopedics recorded the highest patient volume, indicating the greatest service demand among departments.

2. Observation treatment handled the highest patient count, while surgery recorded the highest emergency cases.

3. Routine visits significantly exceeded emergency visits, suggesting healthcare demand was mainly driven by planned care.

4. Patient distribution remained balanced across departments, with no major concentration of healthcare services.


# 💡 Recommendations

1. Increase Orthopedics capacity to support higher patient demand.

2. Review emergency surgery drivers to identify opportunities for earlier intervention.

3. Strengthen preventive healthcare programs to reduce emergency cases.

4. Monitor departmental workload regularly to maintain effective resource allocation.
